Rollback & Restore Defaults

Want to revert to standard firmware? This action will:

  • Restore the original N2030index.html from the backup made during install (removing K1Labs from sidebar).
  • Restore base version string in /opt/algorithm/algorithm_version.txt (removing -k1labs).
  • Reset Git URL in algo_config.json back to official: https://github.com/PachiraMining/Algorithm-official-release-v2.git
  • Reconfigure and restart algorithm_update.service.
